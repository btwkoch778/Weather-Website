
# Weather Forecast Website

A simple weather forecast website built with HTML, CSS, and JavaScript using the Open-Meteo API.

## Features

- Search weather by city
- Current weather information
- 7-day weather forecast
- Responsive design
- Azerbaijan city suggestions

## Technologies

- HTML
- CSS
- JavaScript
- Open-Meteo API

---

# Hava Məlumatı Veb Saytı

HTML, CSS və JavaScript istifadə edilərək hazırlanmış sadə hava proqnozu veb saytıdır. Layihədə Open-Meteo API-dən istifadə olunur.

## Xüsusiyyətlər

- Şəhər üzrə hava axtarışı
- Cari hava məlumatlarının göstərilməsi
- 7 günlük hava proqnozu
- Responsive dizayn
- Azərbaycan şəhərləri üçün axtarış təklifləri

## Texnologiyalar

- HTML
- CSS
- JavaScript
- Open-Meteo API
